// Overview

As Above So Below As Above So Below is an immersive audio-reactive projection mapping installation built in TouchDesigner. The piece transforms a physical space into a large-scale visual experience, mapping a flowing, procedurally generated water wave across four walls, driven by ambient piano music.

Built as a two person team under a tight timeframe, the project was as much an exercise in adapting to constraints as it was in creative computation.

// Process

  • The core visual is a water wave designed using TouchDesigner's mirror and tile functions,transforming a simple input into a complex, flowing form.
  • Procedural geometry and texture mapping techniques were used to craft a specific, intentional visual language throughout.
  • The final output was projection-mapped across four walls, creating a fully immersive, large-scale installation.Photoshop and After Effects were used for additional display assets shown at Pangeo

// Outcomes

  • Initial ideation explored Kinect sensor interactivity, this was scoped down due to time constraints, leading to a more focused solution.
  • Primary contribution was the design and full implementation of the main water wave visual system.
  • A success in creative problem-solving, proving that constraints can sharpen rather than limit a project.
