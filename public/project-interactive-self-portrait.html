// Overview

Interactive Self Portrait Interactive Self Portrait is a personal data visualisation project that explores the relationship between emotional states, music consumption and hormonal cycles. Using data scraped from Spotify and the Flo app, the project maps how internal states influence media choices — and how mood, in turn, connects to physical symptoms. The result is a visual story that is both deeply private and universally relatable.

// How It Works

  • Spotify and Flo data was scraped and analysed to find patterns across mood, music traits and physical symptoms.
  • A scatter plot maps songs by valence and energy, colour coded by mood state (Sad, Happy, Anxious) — revealing how emotional state shapes listening behaviour
  • A second visualisation links Flo tracked moods directly to physical symptoms like back pain, cramps and bloating,surfacing the connection between mental state and body.
  • The full interface was built in Python Dash, designed to make these connections clear and navigable

// Context

  • This project began as a curiosity does the music I reach for actually reflect how I feel?
  • The dataset made the answer undeniable. Music choices, mood and physical symptoms are deeply interconnected. ?
  • It became an exercise in self-introspection using data to reveal personal truths in a way that feels both intimate and analytical.
  • Presented as part of a data visualisation and personal narrative brief.
